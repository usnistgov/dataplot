% This is a sample header for Dataplot generated Latex files.
% You can use the command
%     SET LATEX HEADER FILE  filename.tex
% to specify your own header file.
%
% Note that there are 3 ways to incorporate graphics into the
% LaTeX file:
%
%   1. Define the PGRAPHIC and LGRAPHIC commands.  These will be
%      utilized by Dataplot to import a graph when a DEVICE 2 POSTSCRIPT/
%      DEVICE 2 CLOSE block is entered within a CAPTURE LATEX block.  To
%      use this method, enter the following command before CAPTURE LATEX
%
%         SET LATEX IMPORT PDF LGRAPHIC
%
%   2. Use the graphicx package to import Postscript/PDF.  This works
%      similarly to method 1, but uses slightly different LaTeX syntax.
%      To use this method, enter the following command before
%      CAPTURE LATEX (this is the default setting)
%
%         SET LATEX IMPORT PDF GRAPHICX
%
%   3. Alternatively, you can use the DEVICE 1 LATEX command in the
%      CAPTURE LATEX block to generate the graphs directly in LaTeX
%      using the epic/eepic packages.
%
%   4. Alternatively, you can use the DEVICE 1 LATEX command in the
%      CAPTURE LATEX block to generate the graphs directly in LaTeX
%      using the Tikz package.
%
% If you are generating a stand alone LaTeX formatted graph
% (DEVICE 2 LATEX STANDALONE), it is recommended that you not specify
% a LaTeX header file (Dataplot will insert the needed LaTeX commands
%  automatically).
%
% This version of LaTeX header file is for method 2.
